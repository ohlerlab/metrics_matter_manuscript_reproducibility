# Notes on environment installations
Note that liam is currently unavailable as a package through PyPI or any conda channel. Thus, to obtain the environment detailed in the ```liam_env_no_defaults.yml``` file, please follow the installation instructions from https://github.com/ohlerlab/liam. In practice, you will first install all dependencies in the YAML file except for liam (version 0.1.1) and then install liam (version 0.1.1) from GitHub. 

All other environments can be directly installed from the YAML files.
